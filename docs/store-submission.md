## 3. runFullTrust 사유서 초안

> 본 앱은 기업 고객센터가 자사 고객의 Windows PC 를 원격으로 지원하기 위한 연결 프로그램입니다.
> 화면 공유와 원격 제어 기능을 앱이 직접 구현하며, 다음 Win32 API 를 사용합니다.
>
> - 화면 캡처: GDI `BitBlt` / DXGI Desktop Duplication
> - 입력 주입: `SendInput`
> - 화면 구성 조회: `EnumDisplayMonitors`, `GetSystemMetrics`
>
> 이들 API 는 UWP 앱 컨테이너 안에서 데스크톱 전체를 대상으로 동작할 수 없으므로
> `runFullTrust` 가 필요합니다. 외부 실행 파일을 동봉하거나 내려받지 않습니다.
>
> 앱은 다음을 하지 않습니다.
> - 백그라운드 상주, 자동 실행 등록, 서비스 설치
> - 사용자 모르게 연결 시작 (매 세션마다 상담원이 구두로 전달한 6자리 코드 입력과 명시적 "허용" 필요)
> - 외부에서 추가 실행 파일을 내려받아 실행
> - 원격지원 중 표시창 숨기기
>
> 원격지원이 진행되는 동안에는 화면 오른쪽 위에 항상 표시되는 상태창과 알림 영역 아이콘이 유지되며,
> 사용자는 언제든지 [종료] 를 눌러 즉시 연결을 끊을 수 있습니다.
> 세션이 끝나면 임시 설정 파일과 작업 폴더를 삭제하고 어떤 구성요소도 상주시키지 않습니다.

## 4. 스토어 설명문 초안

**짧은 설명(최대 100자)**

> 상담원과 전화 통화 중에 6자리 코드만 입력하면 되는 간편한 원격지원 연결 프로그램입니다.

**긴 설명**

> RemoteHelp 는 기업 고객센터의 상담원이 고객 PC 를 원격으로 지원할 수 있게 도와주는 연결 프로그램입니다.
>
> 사용 방법
> 1. 상담원과 통화하면서 이 앱을 실행합니다.
> 2. 상담원이 알려주는 6자리 코드를 입력합니다.
> 3. "허용" 을 누르면 상담원이 화면을 보며 도와드립니다.
> 4. 도움이 끝나면 [원격지원 종료] 를 누릅니다.
>
> 안전하게 사용하세요
> - 코드는 1회용이며 10분이 지나면 자동으로 만료됩니다.
> - 원격지원 중에는 화면에 "원격지원 중" 표시가 계속 보입니다.
> - 언제든지 종료할 수 있고, 종료하면 즉시 연결이 끊어집니다.
> - 금융기관이나 수사기관은 원격제어를 요구하지 않습니다. 상담원을 직접 확인한 경우에만 코드를 입력하세요.
>
> 통신 구간은 TLS 로 암호화되며, 세션마다 새로운 접속 비밀번호가 발급됩니다.

**검색 키워드**: 원격지원, 원격제어, 고객센터, 상담, 기술지원, remote support

## 5. 연령 등급 설문 답변 초안

- 폭력/성적 콘텐츠/약물 등: 모두 "없음"
- 사용자 간 상호작용: **있음** (상담원이 사용자의 PC 화면을 보고 제어)
- 개인정보 공유: **있음** (PC 이름, OS 버전, IP 주소가 상담 기록에 남음) → 개인정보처리방침 URL 필수
- 위치 정보 공유: 없음
- 앱 내 구매: 없음 (요금은 기업 대상 별도 계약)

## 6. 인증 테스트 담당자용 안내 초안

> 이 앱은 기업 고객센터가 발급한 6자리 코드가 있어야 동작합니다.
> 인증 심사를 위해 아래 테스트 계정으로 코드를 발급받을 수 있습니다.
>
> 1. https://portal.example.com/login 에 접속합니다.
> 2. 계정: store-review@example.com / 비밀번호: (제출 시 기재)
> 3. [새 세션] 을 누르면 6자리 코드가 표시됩니다(유효 10분).
> 4. 앱을 실행해 그 코드를 입력하고 [허용] 을 누르면 연결됩니다.
> 5. 브라우저 화면의 [원격 시작] 을 누르면 심사자 PC 화면이 표시됩니다.
>
> 테스트 계정은 심사 기간 동안 활성 상태로 유지합니다.

## 8. WACK 실행

```powershell
# Windows SDK 에 포함된 appcert 사용
& "C:\Program Files (x86)\Windows Kits\10\App Certification Kit\appcert.exe" reset
& "C:\Program Files (x86)\Windows Kits\10\App Certification Kit\appcert.exe" test `
    -apptype desktop -packagefullname <PackageFullName> -reportoutputpath .\wack-report.xml
```

자주 걸리는 항목: 금지 API 사용, 디지털 서명, 매니페스트 필수 필드 누락.
