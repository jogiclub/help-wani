# 코드 서명 인증서 선택 가이드

- 조사일: 2026-09-15
- 근거: Microsoft Learn "Code signing options for Windows app developers" (2026-08-29 갱신), SignPath Foundation

## 결론 먼저

| 배포 경로 | 필요한 것 | 비용 |
|---|---|---|
| **Microsoft Store (MSIX)** | 없음. Microsoft 가 대신 서명 | **무료** (개발자 계정 등록만) |
| 직접 다운로드 (EXE) | OV 코드 서명 인증서 | 연 $150~300 |

**무상으로 코드 서명 인증서를 받는 방법은 사실상 없습니다.**
다만 **Microsoft Store 경로를 쓰면 인증서 자체가 필요 없습니다.** Microsoft 가 패키지를 다시 서명하고,
SmartScreen 경고도 뜨지 않습니다. 우리는 MSIX 패키징을 이미 준비해 두었으므로
1차 배포를 Store 로만 하면 인증서 비용 없이 시작할 수 있습니다.

## 선택지 비교

| 방식 | 비용 | 우리 상황 | SmartScreen |
|---|---|---|---|
| Microsoft Store (MSIX) | 무료 | **사용 가능** | 경고 없음 |
| Azure Artifact Signing | 월 약 $9.99 | **사용 불가 (지역 제한)** | 평판 누적 필요 |
| SignPath Foundation | 무료 | 오픈소스 전환 시에만 | 평판 누적 필요 |
| OV 인증서 (DigiCert, Sectigo 등) | 연 $150~300 | 사용 가능 | 평판 누적 필요 |
| EV 인증서 | 연 $400~ | 권장하지 않음 | **OV 와 동일** |
| 자체 서명 | 무료 | 사내 배포 한정 | 설치 차단 |
| 미서명 | 무료 | 권장하지 않음 | 강한 차단 |

### Microsoft Store — 실질적인 무료 경로

MSIX 로 제출하면 인증 통과 후 **Microsoft 가 패키지를 다시 서명합니다.**
인증서를 사거나 갱신할 일이 없고 사용자에게 경고도 뜨지 않습니다.
개발자 계정 등록은 https://storedeveloper.microsoft.com 에서 합니다.

주의: **MSI/EXE 설치 파일로 Store 에 제출하면 Microsoft 가 서명해 주지 않습니다.**
이 혜택은 MSIX 패키지에만 적용됩니다.

### Azure Artifact Signing (구 Trusted Signing) — 한국은 대상 아님

월 약 $9.99 로 가장 저렴하고 하드웨어 토큰도 필요 없지만, 지역 제한이 있습니다.

- 법인: 미국, 캐나다, EU, 영국
- 개인: 미국, 캐나다

**한국 법인은 현재 가입할 수 없습니다.** 향후 지역이 확대되면 1순위로 검토할 만합니다.

### SignPath Foundation — 오픈소스 전용 무료

오픈소스 프로젝트에 OV 수준 서명을 무료로 제공합니다. 개인키는 SignPath 의 HSM 에 보관되고,
공개 저장소에서 CI 가 빌드한 산출물임을 확인한 뒤에만 서명합니다.

조건과 부작용:

- 공개 저장소 + OSI 승인 오픈소스 라이선스가 필요합니다.
- **서명 주체가 "SignPath Foundation" 으로 표시됩니다.** 회사 이름이 아닙니다.

우리 서비스에는 이 부분이 걸립니다. 보이스피싱 경고를 전면에 내세우는 원격지원 프로그램에서
게시자 이름이 우리 회사가 아닌 제3자 재단으로 보이면 고객 신뢰에 역효과가 납니다.
런처만 따로 오픈소스로 공개하는 방안은 기술적으로 가능하지만, 이 표시 문제 때문에 권하지 않습니다.

### OV 인증서 — 직접 배포를 하려면 이것

- 연 $150~300, 전 세계 발급 가능
- 2023년 6월부터 **개인키를 HSM 이나 USB 토큰에 보관해야 합니다.** 파일(.pfx) 보관은 불가합니다.
  대부분의 CA 가 토큰을 함께 보내거나 클라우드 HSM 을 제공합니다.
- 법인 실체 확인에 며칠 걸립니다.

### EV 인증서 — 이제 살 이유가 없습니다

예전에는 EV 서명 파일이 SmartScreen 을 즉시 통과했지만 **2024년에 그 동작이 없어졌습니다.**
지금은 OV 와 똑같이 평판을 쌓아야 합니다. SmartScreen 때문에 EV 프리미엄을 낼 이유는 없습니다.
(이미 보유 중이라면 만료까지 계속 쓰면 됩니다.)

### 자체 서명 — 사내 배포만

기본적으로 신뢰되지 않아 일반 고객 배포에는 쓸 수 없습니다.
다만 고객사 IT 부서가 Intune 이나 그룹 정책으로 인증서를 신뢰 목록에 배포할 수 있는
**기업 내부 배포**에는 유효합니다. 특정 고객사 전용으로 납품하는 경우 검토할 수 있습니다.

## 진행 방침 (2026-09-15 결정)

1. **1차는 Microsoft Store (MSIX) 단독 배포.** 인증서 비용 0원, 경고 없음. → 확정
2. 직접 다운로드 경로는 구현해 두고 `DIRECT_DOWNLOAD_ENABLED=false` 로 꺼 둔다.
3. Store 설치가 막힌 고객이 실제로 얼마나 되는지 운영하며 확인한다.
4. 수요가 확인되면 OV 인증서를 구매하고(연 $150~300) 스위치를 켠다.
5. 한국이 Azure Artifact Signing 대상에 포함되면 그쪽으로 옮긴다.

## 평판에 대해

어떤 인증서를 쓰든 **새로 서명한 파일은 처음에 경고가 납니다.** 중요한 것은 일관성입니다.

- 같은 서명 주체로 계속 배포해야 평판이 누적됩니다.
- 인증서를 바꾸거나 회사명 표기를 바꾸면 평판이 초기화됩니다.
- 따라서 인증서를 살 때는 **회사명 표기를 처음부터 확정**하고 시작해야 합니다.
